04

工程化与部署

工程实践

  • 前后端分离：Vite 开发代理 /api，生产环境由 Vercel rewrite 反代后端。
  • 幂等种子脚本初始化科室、药品、排班与演示账号，环境可一键复原。
  • 生产配置环境变量化：SECRET_KEY / DEBUG / CSRF_TRUSTED_ORIGINS。
  • WhiteNoise 托管静态资源，Gunicorn 作为 WSGI 服务器。

部署方案

  • 前端：Vercel（Root frontend，构建 npm run build，产物 dist）。
  • 后端：Render（Root backend，Gunicorn 绑定 $PORT，workers=1）。
  • 跨域：同源代理，无需额外 CORS 配置。
  • 在线地址部署完成后更新于简历与作品集首页。
